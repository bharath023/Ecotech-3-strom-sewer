# Results (reference run)

Produced by the scripts in the parent folder with the PLACEHOLDER rainfall in rainfall_input.csv
(5-yr sizing storm, 50-yr check storm): 5-yr peak 66 m3/s with no flooding; 50-yr peak 119 m3/s with about 10,000 m3 flooding.
Results depend on the assumed grid and may differ by about 10 percent on another machine.
Open `ecotech3_live_map.html` in Chrome or Edge (online for the base map). `rainfall_used.csv` records the rainfall used.
